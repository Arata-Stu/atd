# Monza 試作の材質

Poly Haven の CC0 テクスチャを同梱している。実行時はローカルファイルを参照する。透視投影の UV は撮影素材の実寸に合わせて繰り返す。

| 配置 | 取得元・作者 | UV 1 枚の幅 |
|---|---|---|
| floor | [Asphalt Floor](https://polyhaven.com/a/asphalt_floor), eye-candy.xyz | 2.3 m |
| wall | [Concrete](https://polyhaven.com/a/concrete), Rob Tuytel | 4.0 m |

配布元の1K JPG（Diffuse、nor_gl、Rough）を使った。色は 1024 × 1024 の JPEG、OpenGL 用法線と粗さは 512 × 512 の PNG に変換した。写真に基づく可視光の材質で、D455 の赤外分光反射率は未測定。[CC0 利用条件](https://polyhaven.com/license)
