# Rev6 Pico 初回確認記録

対象UF2のSHA256と基板番号を記録し、最初はモーター線を外して確認します。実車の動作を含むため、この表はソフトウェアテストの合格では埋まりません。100 HzのTBLE-04SR／サーボ適合もこの段階で確認します。

| 確認 | 合格条件 | 結果・測定値 |
| --- | --- | --- |
| 無通電 | BEC、3.3 V、GND間の短絡なし／実装の極性正常 | 未測定 |
| USBのみ | USB 2 CDC列挙、CDC0 PING→PONG、CDC1 INFO、BEC端子に給電されない | 未実施 |
| 本体LED／USBのみ | v0.2.0-ledのINFO応答、短く2回ずつ点滅、CDC1 LEDでUSB_LINKとpower_ready=0 | 未実施 |
| 本体LED／制御・異常 | プロポ制御＝0.5秒交互、USB制御＝0.9秒点灯、SBUS喪失・HOST timeout・BEC成立後の喪失＝高速点滅。LEDコマンドはPWMを変えない | 未実施 |
| BECのみ | Picoと受信機起動、Jetsonなしで手動PWM、発熱・電圧を記録 | 未実施 |
| USB+BEC | 双方電源・単独切替時の電圧波形、逆流・異常発熱なし | 未実施 |
| GPIO対応 | UV_GOOD物理12番＝GP9。IMU/RPM端子電圧を確認 | 未実施 |
| 起動・RESET・BOOTSEL | サーボ／ESC端子の起動異常パルスなし。パルス停止と中立を区別 | 未実施 |
| PWM | 端子側の周期10 ms、High幅1000/1500/2000 µs、両chの極性 | 未測定 |
| プロポ校正 | CH1/2方向、CH3の2位置と割当、SBUS端点を記録 | 未実施 |
| 受信機喪失 | 手動／HOSTそれぞれで送信機OFF、受信機線断、failsafe flag、50 ms timeout | 未実施 |
| USB異常 | unplug、bus reset、suspend/resume後に旧走行が再開せず、中立再armが必要 | 未実施 |
| HOST timeout | 非中立指令後に送信停止。中立へ移行し、新しい非中立だけで再開しない | 未実施 |
| 受信機なし | 電源投入時からなし→USB操作可、後から受信機接続→抜いてもUSB-onlyへ戻らない | 未実施 |
| 低電圧 | BEC/logic実閾値、出力クランプ、短いdip捕捉、復帰100 ms、旧HOST指令破棄 | 未測定 |
| watchdog | 制御割込みを意図的に止め、PWM残留時間・リセット・復帰中の波形を測定 | 未実施 |
| USB送信詰まり | センサstreamを読まない状態でも手動制御を継続、drop数増加を確認 | 未実施 |
| RPM | センサ供給定格／出力方式／PPR確認、周波数掃引、ノイズ時の制御遅延を測定 | 未実施 |
| IMU | モデル選定・ドライバ追加後、電流・SPI・時刻・欠落・同時負荷を別途確認 | 未対応 |

USB端末のCDC1 `BOOTSEL`更新はBECを切って試します。Jetsonは独立したバッテリー給電を継続します。BEC6 VをPicoの3V3/VSYSへ直接接続してはいけません。
